# E-commerce-DB_NoSQL

Лабораторна робота з дисципліни «Сучасні технології баз даних»: дослідження та реалізація NoSQL баз даних для предметної області електронної комерції. Проєкт передбачає використання PostgreSQL, MongoDB та Redis, порівняння реляційного і нереляційного підходів до зберігання даних, а також тестування їхньої швидкодії.

## Предметна область

Предметна область — платформа електронної комерції з кількома незалежними магазинами. Кожен продавець має власний магазин, каталог товарів, залишки товарів за розмірами та купони. Покупці можуть додавати товари з різних магазинів до одного кошика та оформлювати спільне замовлення, яке розподіляється на підзамовлення за магазинами.

Для дослідження можливостей NoSQL баз даних розглянуто доцільність використання нереляційного зберігання частини даних предметної області, реалізовано відповідні структури та операції, а також їхні аналоги в PostgreSQL.

## Використані технології

- **PostgreSQL** — реляційна база даних для зберігання структурованих даних.
- **MongoDB** — документно-орієнтована NoSQL база даних.
- **Redis** — NoSQL база даних типу Key-Value.
- **SQL** — мова запитів до реляційної бази даних.
- **MongoDB Query Language (MQL)** — мова запитів до MongoDB.
- **Redis Commands** — команди для роботи з даними в Redis.

## Вміст репозиторію

| Файл / папка | Призначення |
|---|---|
| `postgres/` | Реалізація відповідної частини предметної області в PostgreSQL: реляційна структура даних та SQL-запити. |
| `mongodb/` | Реалізація відповідної частини предметної області в MongoDB з використанням документної моделі зберігання даних. |
| `redis/` | Реалізація базових операцій із даними в Redis з використанням структури Key-Value. |
| `benchmarks/` | Тестування та порівняння швидкодії відповідних реалізацій у PostgreSQL і MongoDB. |
